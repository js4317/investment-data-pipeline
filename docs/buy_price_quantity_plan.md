## 1. 목적

대시보드 매수 후보 표시에 **"지금 얼마에, 얼마나 살까"** 에 대한 참고 정보를 추가한다.

핵심 원칙:
- **정보 제공**이지 **매수 지시**가 아니다. "이 가격에 사세요"가 아니라 "이 가격대가 과거 기준으로 싼 편이다"를 보여주는 것.
- 판단은 투자자가 한다.
- 근거 없는 숫자는 표시하지 않는다. 계산 불가 케이스는 "—"로 표시.

## 2. 적정 매수가

### 2-1. 방법론 후보

#### A. PBR 기반 (가장 단순)

```
적정가 = BPS × 목표PBR(업종)
현재 괴리율 = (현재 PBR / 목표PBR - 1) × 100
```

- 장점: 계산 단순, 데이터 있음 (BPS는 DART에서 가져옴)
- 단점: 목표 PBR을 업종별로 하드코딩해야 함. ROE가 낮아도 PBR이 낮으면 저평가로 오인.

#### B. ROE 조정 PBR (Gordon Growth 파생)

```
이론적 PBR = ROE / 요구수익률(r)
적정가 = BPS × (ROE / r)
```

r = 무위험이자율 + 리스크프리미엄 (예: 3.5% + 5% = 8.5%)

- 장점: ROE가 낮으면 낮은 PBR이 정당화됨 — 업종 왜곡 줄어듦
- 단점: r(요구수익률)을 어떻게 정하느냐가 결과를 크게 좌우함. 파라미터 민감도 높음.
- 예시: ROE 8%, r 8.5% → 이론 PBR 0.94 → 현재 PBR 0.6이면 약 36% 할인 상태

#### C. 52주 기술적 지지선

```
참고가 = 52주 저가 + (52주 고가 - 52주 저가) × 0.3
```

- 장점: 펀더멘털 무관, 단기 매수 타이밍 참고용
- 단점: 추세 무관 — 하락 추세에서 지지선을 뚫으면 의미 없음
- 용도: 단독 사용보다 A/B 방법론의 보조 정보로 표시하는 게 적절

#### D. 분기 실적 기반 PER 적정가 (가장 복잡)

```
정상화 EPS = 최근 4분기 합산 EPS (일회성 제거 후)
적정가 = 정상화 EPS × 목표PER(업종)
```

- 장점: Cyclical 업종에서 PBR보다 정확할 수 있음
- 단점: DART 분기 데이터 자동 추출 안정성 검증 필요 (Structural Trend Stage 1 선행 조건과 동일). EPS 일회성 조정이 주관적.
- **현재 상태**: Structural Trend DART 검증 전까지 사용 불가

---

### 2-2. 방법론 비교

| 방법 | 데이터 필요 | 업종별 조정 | 계산 복잡도 | 신뢰도 |
|------|------------|------------|------------|--------|
| A. PBR 단순 | BPS | 목표PBR 테이블 | 낮음 | 중간 |
| B. ROE 조정 PBR | BPS + ROE | r만 고정 | 중간 | 높음 |
| C. 52주 기술 지지선 | 52주 고/저가 | 불필요 | 낮음 | 낮음 (보조용) |
| D. PER 기반 | 정규화 EPS | 목표PER 테이블 | 높음 | 높음 (구현 후) |

**권장 구현 순서**: B → A를 보조로 → C를 참고 추가 → D는 DART 검증 후

## 3. 적정 매수량

### 3-1. 방법론 후보

#### A. 포트폴리오 비중 기반 (단순)

```
목표 비중 = 사용자 설정 (예: 종목당 5%)
매수량 = floor((총자산 × 목표비중) / 현재가)
```

- 장점: 직관적, 구현 단순
- 단점: 총자산을 어디서 가져오느냐 → v9 브로커 연동 필요. 또는 사용자 수동 입력.
- 현재 구현 가능 여부: 브로커 없으면 총자산 불명 → 수동 입력 모드로 우선 구현 가능

#### B. 리스크 예산 기반

```
허용 손실 = 총자산 × 리스크예산(예: 1%)
손절선 = 매수가 × (1 - 손절비율, 예: 8%)
매수량 = floor(허용손실 / (매수가 × 손절비율))
```

- 장점: 손실 한도가 명확. 종목별 변동성 간접 반영.
- 단점: 손절비율 설정이 필요. 실제 손절을 하지 않으면 계산 의미 없음.

#### C. Kelly Criterion

```
f = (bp - q) / b
  b = 기대수익률, p = 승률, q = 1-p
```

- 장점: 이론적으로 장기 자산 극대화
- 단점: 정확한 승률과 기대수익률이 필요 → 캘리브레이션 n≥100 + 알파 통계적 유의성 확보 전까지 입력값 자체가 불신뢰
- **현재 상태**: 🔒 v10 이후

---

### 3-2. 권장 구현 순서

1. **v9.0**: A 방법 (포트폴리오 비중 기반) — 브로커 연동 후 총자산 자동 계산
2. **v9.1**: B 방법 (리스크 예산) — 손절선 설정 UI 추가 후
3. **v10**: C 방법 (Kelly) — 캘리브레이션 완료 후

## 4. 대시보드 표시 설계 (UI 초안)

매수 후보 카드 1줄 예시:

```
🟢 삼성전자 — 85점  ·  63,200원  +2.3%  🔥 Strong
   적정가 57,800원 (-8.5% 괴리)  ·  목표비중 5% = 79주
   추천 이유: Valuation 25 / Supply 20 / 외인 순매수 8일 연속
```

- 적정가 계산 가능한 종목만 표시. 지주사/Cyclical 업종은 "—"
- 매수량은 총자산 입력 전까지 "총자산 미설정" 안내
- 괴리율 음수(-) = 현재가가 적정가 아래 = 저평가 구간

아래 조건 모두 충족 전까지 구현하지 않는다:

## 6. 하지 않을 것

- 복잡한 DCF 밸류에이션 (입력 가정이 너무 많음)
- 실시간 시세 기반 자동 매수 추천 (v9도 자동 주문 미지원)
- ML 기반 적정가 (표본 부족, 과적합 위험)
- "이 가격에 사세요" 직접 지시 문구
